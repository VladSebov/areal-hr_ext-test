# Должности (`/positions`)

Модель данных `Position`:

- `id` (number) - Уникальный идентификатор
- `name` (string) - Название должности
- `deletedAt` (string|null) - Дата мягкого удаления

## GET /positions

Возвращает список активных должностей (без удалённых), отсортированный по `id` ASC.

Ответ: массив Position.

Пример:

```json
[
{ "id": 1, "name": "Генеральный директор", "deletedAt": null },
{ "id": 2, "name": "Технический директор", "deletedAt": null },
{ "id": 3, "name": "Системный администратор", "deletedAt": null }
]
```

## GET /positions/:id

Возвращает одну должность по ID.

Параметры пути: `id` (number)

Ошибки: 404 - не найдена.

## POST /positions

Создаёт новую должность.

Тело (CreatePositionDto):

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `name` | string | да | Название должности |

Пример запроса:

```json
{
"name": "Ведущий разработчик"
}
```

Ответ: 201 Created, созданная Position.

## PATCH /positions/:id

Обновляет должность. Все поля в UpdatePositionDto опциональны.

Параметры пути: `id` (number)

Тело: `{ "name": "Новое название" }`

Ошибки: 404 - не найдена.

Ответ: обновлённая Position.

## DELETE /positions/:id

Мягкое удаление должности (устанавливает `deletedAt`).

Ошибки: 404 - не найдена.

Ответ:

```json
{
"message": "Position #42 soft-deleted"
}
```

## Примечания

- При старте приложения автоматически создаются начальные должности (seed), если таблица пуста.
- Должности используются в кадровых операциях (`hr-operations`).
