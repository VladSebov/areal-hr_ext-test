# Справочник API

## Общие сведения

Документация описывает REST API системы управления персоналом **Areal HR App**.

- **Базовый URL:** `/api/v1`
- **Формат данных:** Все запросы и ответы передаются в формате `application/json`.
- **Авторизация:** Большинство эндпоинтов защищены Guard-ами. Для доступа требуется передавать валидную сессионную Cookie или Bearer-токен в заголовке `Authorization: Bearer <token>`.
- **Кодировка:** UTF-8.
- **Временная зона:** UTC (даты передаются в формате ISO 8601: `YYYY-MM-DD` или `YYYY-MM-DDTHH:MM:SSZ`).

## Статусы ответов

| Код | Описание |
|-----|----------|
| 200 | Успешный запрос (GET, PATCH, DELETE) |
| 201 | Успешное создание (POST) |
| 400 | Неверный запрос (невалидные данные, логическая ошибка) |
| 401 | Требуется авторизация |
| 403 | Доступ запрещён |
| 404 | Ресурс не найден |
| 500 | Внутренняя ошибка сервера |

## Структура ошибок

При ошибке сервер возвращает JSON с полем `message` (строка или массив строк) и опционально `error`, `statusCode`.

```json
{
  "statusCode": 404,
  "message": "Employee with ID 42 not found",
  "error": "Not Found"
}
```
