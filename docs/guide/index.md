# Руководство по приложению

В данном разделе описана структура данных и логика работы системы Areal HR App, с которой взаимодействует специалист по кадрам.

## Структура данных Areal HR App

Ниже приведено описание таблиц и их полей, которые заполняются специалистом по кадрам.

### 1. Организации
Справочник юридических лиц компании.
* **Наименование** — официальное название организации.
* **Комментарий** — примечания или реквизиты.

### 2. Отделы
Структурные подразделения. Внутри отдела могут быть указаны другие отделы, для этого у дочернего подразделения должен быть указан родитель.
* **Организация** — к какой организации относится отдел.
* **Наименование** — название отдела (например, *Отдел разработки*, *Бухгалтерия*).
* **Родитель** — ссылка на вышестоящий отдел для создания иерархии.
* **Комментарий**.

### 3. Должности
Штатные единицы организации.
* **Наименование** — название должности (например, *Системный администратор*).

### 4. Сотрудники
Персональные карточки работников.
* **ФИО:** Фамилия, Имя, Отчество.
* **Дата рождения**.
* **Паспортные данные:**
    * Серия и Номер
    * Дата выдачи
    * Код подразделения
    * Кем выдан
* **Адрес регистрации:** Область, Населенный пункт, Улица, Дом, Корпус, Квартира.
* **Скан паспорта** — ссылки на прикрепленные файлы документов.

### 5. Файлы
Хранилище загруженных документов и сканов.
* **Название** — имя файла для отображения в системе.
* **Файл**.

## Кадровые операции

Каждое изменение статуса сотрудника оформляется в виде кадровой операции. Каждая операция жестко связана с конкретным сотрудником.

| Тип операции | Заполняемые данные | Результат в системе |
| :--- | :--- | :--- |
| **Принятие на работу** | Отдел, Должность, Установка зарплаты | Создается активный профиль, фиксируется начальная ставка. |
| **Изменение зарплаты** | Новая ставка зарплаты | Обновляется оклад сотрудника. |
| **Изменение отдела** | Новый Отдел, Новая Должность | Сотрудник переводится в другое подразделение. |
| **Увольнение с работы** | Причина увольнения | Сотрудник увольняется (деактивируется пользователь и карточка). |

## История изменений

Система автоматически логирует любые действия кадровика для обеспечения подотчетности.

* **Дата и время операции** — точный момент фиксации изменения.
* **Кто изменил** — ссылка на пользователя (HR-специалиста), выполнившего действие.
* **Объект операции** — тип сущности, которая была изменена:
    * `Организация`
    * `Отдел`
    * `Должность`
    * `Сотрудник`
    * `Кадровая операция`
* **Измененные поля** — история данных в формате "было / стало" (например, старая и новая зарплата).
